# سَلى SALA — نسخة بثلاث صفحات

## الصفحات
- `index.html`: واجهة الزبون الرئيسية، بدون منتجات افتراضية.
- `seller.html`: رابط مستقل لإرسال طلب الانضمام كبائع.
- `admin.html`: لوحة إدارة محلية لإضافة/تعديل/حذف المنتجات، مراجعة طلبات البائعين، وتغيير إعدادات الواجهة.

## التشغيل السريع
1. فك ضغط المشروع.
2. افتح مجلد `SALA` في Visual Studio Code.
3. شغّل `index.html` باستخدام Live Server.
4. رابط صفحة البائع: `seller.html`، ورابط لوحة الإدارة: `admin.html`.
5. كلمة مرور الإدارة الأولية: `SALA@2026` ويمكن تغييرها من إعدادات لوحة الإدارة.

## مهم جدًا قبل النشر
هذه نسخة واجهة أولية تعتمد على `localStorage`. البيانات تظهر فقط في المتصفح الحالي، لذلك طلبات البائعين لن تصل من جهاز البائع إلى جهاز الإدارة، والمنتجات التي تضيفها الإدارة لن تتزامن تلقائيًا مع أجهزة العملاء. كلمة مرور لوحة الإدارة محفوظة في المتصفح وليست حماية خادم حقيقية. لا تنشر لوحة الإدارة على الإنترنت بهذه الصورة ولا تستخدمها لحفظ بيانات حساسة.

لتحويلها إلى سوق فعلي متعدد المستخدمين، يلزم إضافة خادم وقاعدة بيانات ومصادقة وصلاحيات آمنة (مثل Flask + SQLite/PostgreSQL أو Supabase مع سياسات صلاحيات).

## تجهيز أندرويد
المشروع يحتوي إعدادات Capacitor. يتطلب Node.js وAndroid Studio. من Terminal داخل مجلد المشروع:
```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```
بعد فتح Android Studio اختر Build > Build APK(s). لم يتم تضمين APK جاهز في هذه الحزمة.

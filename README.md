# SALA — سَلى

واجهة أولية عربية RTL لسوق إلكتروني متعدد البائعين، مبنية بـ HTML وCSS وJavaScript.

## تشغيل المشروع
1. فك ضغط الملف.
2. افتح مجلد `SALA` في Visual Studio Code.
3. شغّل `index.html` عبر إضافة Live Server أو استضافة محلية تدعم HTTP.
4. يلزم اتصال بالإنترنت لخط Google Fonts وصور المنتجات الخارجية.

## الموجود حاليًا
- تصميم متجاوب للكمبيوتر والهاتف.
- صفحة رئيسية وأقسام ومنتجات وبحث وفرز وتصفية.
- تفاصيل المنتجات والمفضلة والسلة وتعديل الكميات.
- نماذج واجهة الحساب والانضمام كبائع.
- نموذج ملخص طلب محفوظ محليًا على الجهاز.
- PWA manifest وService Worker مبدئي.

## مهم قبل النشر
هذه نسخة واجهة أولية. الحسابات، صلاحيات العملاء والبائعين والإدارة، قاعدة البيانات، رفع الصور، الطلبات الحقيقية، الدفع الإلكتروني، الشحن والإشعارات غير مربوطة بعد. بعض بيانات التفاعل تحفظ في `localStorage` على الجهاز الحالي فقط، ولا تُرسل إلى الإدارة أو إلى بائع.

الخطوة التالية: إعداد مشروع Supabase، جداول PostgreSQL وسياسات RLS، ثم ربط المصادقة والمنتجات والصور بطريقة آمنة. لا تضع مفتاح `service_role` أو أي سر في `app.js`.

## منع النسخ بالضغط المطوّل
تم تعطيل تحديد النص وقائمة النسخ بالضغط المطوّل على واجهة التطبيق. تبقى حقول الكتابة قابلة للتحديد والتحرير حتى يستطيع المستخدم كتابة بياناته.

## تجهيز مشروع أندرويد باستخدام Capacitor
هذه الملفات تجهّز المشروع للتحويل إلى تطبيق أندرويد، لكنها لا تتضمن APK جاهزًا.

المتطلبات: Node.js LTS وAndroid Studio مع Android SDK.

من Terminal داخل مجلد `SALA` نفّذ:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

بعد فتح المشروع في Android Studio، انتظر اكتمال المزامنة ثم اختر Build > Build APK(s) لإنشاء APK للتجربة. عند تعديل ملفات HTML/CSS/JavaScript نفّذ `npx cap sync android` مجددًا.

ملاحظة: هذا يستخدم Capacitor لتغليف واجهة الويب كتطبيق أندرويد قابل للتطوير. الحسابات وقاعدة البيانات والدفع والطلبات الحقيقية ما زالت تحتاج إلى ربط backend آمن قبل الإطلاق.
